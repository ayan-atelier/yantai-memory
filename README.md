# 砚台 · 叙事记忆（因果模型开发版）

> 这是 `0.3.1-dev` 开发副本，不要安装到日常云端交接环境。日常基线仍是记忆 `0.3.0` + 存档同步 `0.1.4`。

本开发线保留 `0.3.0` 旧备份读取能力，同时把事件补充为行动、原因、结果、后果和证据，并将案件、线索、任务、悬念与约定分成开放线程。完整历史仍保存在本地；发送给下一次整理请求的是有上限的当前上下文投影。

在“API 与设置 → 数据管理”中，导入旧备份本身不会调用 API；导入后可以让内置小助手生成迁移预览。预览只改摘要和开放线程，原始逐轮事件不删除，确认后才写入一条可撤销的迁移记录。

把完整的 `yantai-memory` 文件夹放到 `SillyTavern/data/你的账号目录/extensions/`，确保位置是 `extensions/yantai-memory/manifest.json`，然后刷新酒馆。

入口仍是：**输入栏三横菜单 → 叙事记忆**。扩展设置面板也有入口。插件不依赖酒馆助手，不向输入框添加按钮。

## 这版保留的记忆功能

原有功能全部保留：主 API 或自定义第二 API、可编辑记忆预设、按轮自动整理、一次请求批量整理、聊天世界书绑定、查看逐轮记录与累计摘要、待办／约定／誓言、修订备注、失败保留旧记忆、重生成回退、分支处理、备份导入导出、最近原文窗口和旧版静读记忆读取。

当前聊天页只保留日常整理和纠正；备份、导入和迁移已移到“API 与设置 → 数据管理”，避免打断正常使用。旧版的“续写参考”不再生成或注入，旧设置仍可读取但不会继续产生未来剧情建议。

记忆预设明确把输入视为酒馆中的虚构角色扮演资料，只记录已经发生的主线事实。状态栏、行动选项、AIRP 附加组件、旧 MEMORY 栏和明确标记的 IF／番外不会污染主线记忆。

## 砚台小助手

“砚台小助手”是手动打开的工具，不参与每轮对戏。它可以：

- 生成一级或二级记忆压缩，并保留完整逐轮记录；
- 撤销压缩，恢复完整记忆视图；
- 以温和、具体的方式解释记忆插件、预设、世界书和常见酒馆问题。

默认只在记忆估算过长时提醒，不会自动调用压缩。高级设置可以打开自动压缩并指定阈值；自动压缩只在主回复和普通记忆整理完成后的空闲阶段运行，失败时保留原记忆。Token 数为估算值，不代表服务商账单中的精确用量。

默认仍是“纯记忆”模式：导演控制台关闭时，记忆请求和注入行为保持旧版逻辑。

明确以 `$` 开头、并写出“暂停当前剧情／IF／番外／外传／小剧场”等独立拍摄要求的轮次，会被标记为番外并跳过主线记忆整理。它仍留在酒馆聊天记录里，但不会改变主线摘要、事项、导演状态或下一轮的主线事实。普通以 `$` 开头的对白、金额和指令不会因为符号本身被跳过。

## 导演控制台

导演控制台和记忆整理共用同一次 API 请求，不会先调用一次导演、再调用一次回复。它的运行台与历史记忆分开保存：历史只记录已经发生的事实，运行台只服务下一轮生成，不会滚成新的剧情事实。

在“API 与设置”中选择：

- **关闭导演控制台**：只使用记忆。
- **兼容提示·通用预设**：给任意角色卡和预设提供低侵入的连续性、角色边界和自然交接提示，不改写文风、视角、语言、字数或卡片人格。
- **完整导演·砚台预设**：配合砚台连续剧导演预设，提供频道、节奏、上一拍、角色目标、玩家边界、风险和交接点。

导演控制台现在是轻量的“连续性场记”，不是第二套正文预设。它保存频道、节奏、上一拍、可核对的时间／地点／在场人物／知情范围、角色眼下要处理的事，以及玩家授权下的自然交接。当前 AIRP 预设负责本轮导演、演员、频道调性、文风和字数；导演控制台负责跨轮不漂移，换用别的预设时也能继续工作。

两种导演模式都遵守证据门槛：没有证据就留空或沿用上一版，不把普通照顾、沉默、靠近或一次配合改写成掌控、占有、臣服或关系升级。玩家授权模式可以记录严格对戏、有限接续或完整扩写，但不会越过当前预设、卡片和本轮明确要求。导演运行台字段损坏时，已成功的记忆仍会保存，上一版运行台会继续使用。

## 安装注意

不要同时启用旧版「砚台 · 让故事顺手一些」、旧版「砚台 · 导演运行时」和本扩展。它们会重复整理或重复注入提示词。旧聊天和旧世界书不会被删除；停用旧扩展并刷新后，本版会继续读取兼容的记忆备份。

最低 SillyTavern 1.16.0；当前仍支持单角色聊天。主 API 跟随模式要求酒馆使用聊天补全连接；也可以在设置中改用 OpenAI 兼容的自定义 API。API Key 只保存在当前浏览器，不会进入备份。
