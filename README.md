# 砚台 · 叙事记忆 (Yantai Memory)

把经过记清，把故事留给你——专为 SillyTavern（酒馆）百轮以上长线角色扮演打造的**分卷锁定防失忆 · 轻量模型友好**叙事记忆插件。

## 安装方式

在酒馆 **扩展（Extensions）→ 安装扩展（Install extension）** 中填入仓库地址一键安装：

```text
https://github.com/ayan-atelier/yantai-memory
```

安装后刷新页面，入口位于：**输入栏左侧 `☰` 三横菜单 → 叙事记忆**（扩展设置栏中亦有入口；若安装了「ST伴侣」，可直接协同管理并复用副 API 通道）。

---

## 核心特性

1. **新聊天默认无感启用 · 与角色世界书天然共存**
   - 打开任意新角色对话即自动启用，默认**每 3 轮整理一次**，首次满轮自动创建并绑定专属聊天世界书。
   - 与角色卡自带的「角色世界书」完全叠加生效、互不覆盖，且记忆条目默认关闭递归触发以防污染设定扫描。
   - 主回复默认保留**最近 5 轮完整对话原文**，并将前情记忆置于这 5 轮之前（深度 12），时间线严丝合缝。

2. **300+ 轮不丢记忆的三层长程架构**
   - **锁定分卷史册（永不重洗旧卷）**：每满一卷（默认 24 轮）自动封存锁定。后续轻量模型每 3 轮只需整理当前在途新卷，绝不反复重写前几百轮旧摘要，从根源杜绝长线“传话筒式失忆”。
   - **关键信物与长期锚点账本**：自动汇总跨百轮的关键信物／凭证最新归属状态、核心里程碑与长期约定，哪怕第 3 轮送出的信物到第 300 轮依然清晰在册。
   - **双方知情差防读心护栏**：明确记录单方秘密与场外动作的知情边界，防止角色未卜先知。

3. **专为轻量整理模型（Flash / DeepSeek / Haiku 等）减负容错**
   - **三种灵活连接**：支持一键复用 ST伴侣「副 API 通道」、跟随酒馆主 API 并单独点选**同站轻量模型**（无需重复填密钥）、或配置独立自定义 API 并**一键拉取模型列表**。
   - **输入降噪与自愈解析**：自动剥离 `<think>` 思考链、四选一 `<选项区>`、场外 `<锐评>` 等非事实噪音，保留 `<time>` 时空栏；内置宽容 JSON 提取与尾随逗号修复，避免轻量模型因细微格式差异报错重跑。
   - **番外自动隔离**：以 `$` 开头并写明暂停当前剧情／IF／番外／小剧场的轮次自动跳过主线归档。

4. **铁打防丢保护与 `/hide` 隐藏楼层完美兼容**
   - **完美兼容 `/hide` 隐藏楼层**：无论是先整理记忆再 `/hide` 隐藏旧楼层、还是先 `/hide` 再点整理，世界书记忆永不丢失，且已隐藏楼层照常可读可归档（长对话屏幕楼层防卡顿卸载由「ST伴侣 · 流畅渲染引擎」独立承载）。
   - **前文改字零丢失 & 内部保险箱**：回前文修改错别字／切换开场白自动重锚定续接，绝不清空已归档世界书；删楼回退自动将原完整记忆存入 0 Token 内部保险箱，随时支持 0 请求一键恢复。
